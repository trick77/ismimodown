Prefill cost

TTFT at 4 000 input tokens minus TTFT at 40 — what prefill actually costs. A widening gap catches a batching change or a requantisation, neither of which a small probe can see. The large prompt carries a random nonce first, so the prefix cache always misses and this is real prefill rather than a cache lookup.

Inter-token latency

Median gap between output tokens. ITL leads rather than gross tokens/sec: at ~70 output tokens the decode window is only ~1.5 s, so gross throughput is structurally noisy, while ~70 intervals give a solid median.

Edge versus everything else

The TCP handshake is measured in the same 5-minute cycle as the inference call, so this split is measured rather than inferred.

This is not “model time”. The handshake terminates at the TLS edge. Xiaomi runs no European GPUs, so any backhaul between that edge and the actual compute sits inside the right-hand bar, along with queueing, prefill and scheduling. The boundary is real and useful — it just isn't the one it might look like.

The wire itself

Time to complete the TCP handshake on port 443 — no TLS, no HTTP, no auth, no tokens. TCP rather than ICMP: echo is routinely dropped or deprioritised by routers, so a timeout would carry no information. Two reference hosts sit alongside it — one in Singapore, one in Europe — which is what separates “MiMo's edge is down” from “the route to Singapore is degraded” from “our own uplink is down”. Both are public hosts on the open internet; neither is localhost, because a machine pinging itself proves nothing about its uplink.

Methodology

Published in full, including the request shape. A benchmark that hides how it calls the API is asking to be trusted rather than checked.

Three probes, one aligned cycle

  • ping — TCP handshake to token-plan-sgp.xiaomimimo.com:443. No TLS, no HTTP, no auth, no tokens. Free.
  • infer — ~40 input tokens, a rotating factual question, 2–3 sentences out. Every cycle.
  • wide — ~4 000 input tokens, 300 output cap. Every 12th cycle, hourly.

Everything fires inside the same tick, 5 minutes ± 30 s of jitter, so subtracting network from TTFT is exact rather than interpolated against a nearby sample.

Why TCP, not ICMP

ICMP echo is dropped or deprioritised by routers as routine policy, so a timeout would carry no information. It also needs CAP_NET_RAW, which forces a privileged container. A TCP handshake to port 443 traverses the same path, through the same firewalls, as the inference call itself.

Reasoning is off

Disabled on every request. Reported reasoning tokens are asserted to be zero; a non-zero value is treated as a regression, not a datum.

Prompt caching

The 40-token probe needs no cache defeat — nothing caches below ~1 000 tokens. The 4 000-token probe prepends a random nonce before the document, because prefix caches key on the leading blocks: varying anything after the document would leave the expensive part matching and turn a prefill measurement into a cache lookup.

Retention

Raw samples are kept for three months and then deleted. There are no rollups, so three months is the longest window offered. Timestamps are Europe/Zurich, 24-hour.

Timeouts

  • TCP handshake — 5 s
  • Dial + TLS — 10 s
  • Response headers — 60 s
  • Time to first token — 150 s
  • Idle between chunks — 45 s
  • Overall deadline — 240 s

A timeout is a recorded sample, never a dropped one. Failed runs are excluded from latency percentiles and counted in availability — otherwise a 240 000 ms timeout lands in the median and an outage reads as catastrophic latency instead. Windows with fewer than 20 successful samples report “insufficient data” rather than a number.
