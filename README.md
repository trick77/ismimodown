# mimostats

Live at **[mimostats.trick77.com](https://mimostats.trick77.com)**.

A continuous latency monitor for Xiaomi MiMo, measuring from a single European egress every five
minutes. It separates how long it takes to *reach* the endpoint from what happens once you're
there — and says, in plain English, whether anything is wrong.

Methodology, scope and caveats are on the site.
